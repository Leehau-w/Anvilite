# 首页精简、多习惯卡片与完成任务趋势（2026-10-22）

## 用户要求及结果

继续在 codex/legacy-review 支线上进行局部功能调整：移除待反馈卡片的静态拖入说明，快速创建和卡片筛选按钮仅显示分类名称；多个任务卡片统一名为“任务”，习惯同样支持多个实例和独立分类；原成长趋势改为可按完成数量或实际用时查看的完成任务趋势。

## 数据与交互规则

- 待反馈卡片仅在有效拖动进入时显示释放提示，空闲时不再显示用户指定的小字。先前已去掉的任务紫色状态副行保持去除。
- 快速创建选择框和卡片筛选按钮移除可见“分类”前缀，单选显示分类名，多选显示名称列表，未选择显示“未选择”。无障碍名称保留控件含义；长名称省略，完整内容可在弹层查看。
- 所有任务卡片统一标题，习惯卡片亦统一标题。恢复卡片列表用分类摘要区分同名实例，实际操作以稳定 ID 关联，不依赖标题和编号。
- 原 habits ID 与旧布局保留，新增 habits:UUID，CardLayout.habitFilter 与任务筛选使用相同的单/多/全部结构。单选最多一个，多选可为空；新卡追加到原布局下方，不挪旧卡、不复制习惯记录。
- 习惯卡片过滤今日到期 active、本周期完成及空状态，显示和操作同步到同一记录。单分类卡片添加习惯时沿用所选分类。排序只置换当前到期活动习惯的原类别槽位，其他分类、非今日、隐藏、删除或完成习惯不被改写。
- 隐藏保留实例及筛选，可按原 ID 恢复。备份验证 habitFilter 结构；导出再导入、冷重载、旧无筛选及缺 dashboard 字段均保留原有恢复语义。
- 完成任务趋势直接使用 taskStore 的当前 done 主任务和有效 completedAt，排除已删除记录，隐藏仍计入。撤销、删除和修改实际用时会即时反映，不依赖 XP 或成长事件，不混入跳过、习惯及其他事件。
- 时间是已完成任务的 actualMinutes，缺省/非法/负数防御为 0，不计算预估时长或等待时间。按完成时间的本地日期及四时段汇总；月/周和数量/用时可切换，色阶只参考当前显示范围，提示同时显示数量与分钟。

多卡片交叉检查额外修复一个计时入口边界：同帧在一张卡完成习惯后，另一张卡捕获的旧开始按钮可能启动已完成习惯计时。现于卡片操作入口重读当前今日 active 记录再决定开始或暂停；旧完成行撤销绑定当次 actionId。DOM 回归确认完成用时只结算一次，跨卡旧按钮不启动计时，完成与撤销奖励均只处理一次，未改变习惯周期规则。
