# 里程碑编辑小修验收（2026-10-23）

当前支线：codex/legacy-review；基于已发布 v0.4.0（9c4531a）。本次小修纳入 v0.4.1 发布，不改动原发布标签和安装包。

## 用户要求与实现

- 移除自建里程碑卡片的“手动记录”小字；实际任务、习惯记录仍保留来源说明。
- 里程碑编辑支持标题、日期及原有备注，新增记录也可选择日期。日期精确到日，卡片不再显示时分秒。
- 空标题、缺少日期或无效日历日期不可保存；取消不写入，写入失败保留编辑窗口并显示失败提示。新建保存失败回滚本次新增记录，恢复存储后重试不重复。

## 数据约束

标题和日期使用 growthEvents.details 的可选 milestoneTitle / milestoneDate 保存。原始事件标题、时间戳、类型、稳定实体及完成记录 ID、用时和旧奖励信息不变。个人数据、能力图谱和档案馆的真实完成统计继续读取原始业务记录。

旧记录没有新增字段时，沿用原标题和原时间戳的本地日历日期；旧奖励事件上的个人备注以中性里程碑展示，编辑后清空备注仍保留该个人纪念。新增元数据纳入备份校验，现有备份格式版本不变，旧 v0.3+ 记录可继续读取。保存合并当前记录的元数据；持久化失败时仅回滚本次编辑字段，保留无关事件和后续变更。
