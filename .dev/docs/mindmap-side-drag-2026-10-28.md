# 思维导图分支拖拽换边（2026-10-28）

当前 codex/legacy-review 支线，基于已发布 v0.4.2。本次仅实现拖拽换边，不改版本，不提交、推送或重新发布安装包，不混入 main 工作区改造。

## 复现与交互

- 已在隔离 Edge 使用 v0.4.2 产物复现：右侧分支拖到中心节点左侧空白处后，方向与持久化内容均不变。Mind Elixir 5.15.1 原生拖拽只处理具体节点目标，空白落点直接取消。
- 新增空白落点补充：单支分支拖到中心节点另一侧的画布空白处后，整支按该侧保存 direction=0/1；嵌套分支提升为中心节点下的一级分支，后代、展开/折叠状态及任务/子任务引用保留。
- 拖到具体节点上仍由原生行为处理，保留子节点投放与排序；多选继续走原生行为。点击、根节点、未激活拖拽的触摸滑动、画布外、同侧和中心附近的空白投放不触发换边。
- 换边只调整导图结构，保留实际任务归属、标题、状态、子项、用时和计时字段。标题同步、任务转换与备份规则复用原 store，不更改 schema。

## 实现与取消

- 新增 mindMapSideDrag.ts，只复用现有原生拖拽会话；确认 ghost 已激活、单选来源一致后，在原生容器 pointerup 清理完成后的 host 冒泡阶段补充空白跨侧保存。
- 通过 elementFromPoint 和根节点实际 clientRect 判定落点，避免 pointer capture 源 target 与缩放/平移坐标误判；冻结起拖 revision，传空 titleEdits，不把旧投影标题写回实际任务。
- 原生 operation 优先清除补充手势，避免双重提交。Escape、失焦、pointercancel、外部刷新和卸载清理会话；刷新前给原生容器 pointercancel，避免残留 ghost、边缘滚动和访问已移除的 DOM。
