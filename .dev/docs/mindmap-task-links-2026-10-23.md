# 导图任务标题与子任务关联（2026-10-23）

当前 codex/legacy-review 支线，承接 Mind Elixir 首版和待反馈/Enter 小修。保持 v0.4.1 版本，不提交、推送或发布安装包，不改 D 盘主工作区。

## 用户行为

- 任务关联节点显示实际任务标题，在任务弹窗或导图中改名会双向同步；同一任务在其他导图的引用同步回显。导图名称与已关联根任务的标题独立。
- 关联已有任务、节点转任务时，把普通后代按原层级转换为实际嵌套子任务；之后新增普通分支也转换。保留任务原有子项，已独立关联任务的分支保持独立，重复关联不复制同名或已转换节点。
- 首次打开/切换导图时，已有任务关联的普通后代通过相同保存动作补齐一次；没有任务关联或已经映射的图不写任务。失败显示错误，不随任务或语言变化循环重试。
- 子任务节点显示自己的实时标题与完成状态，并提供打开所属任务入口。已完成父任务转换出的新子项同时为完成状态，保持父任务状态、完成来源、实际用时、计时和旧奖励。
- 删除节点或整张图、解除所属任务关联都不删除实际任务/子任务。父关联解除会清除其依赖子引用；子任务节点不提供会被祖先立即重新映射的单独解除入口。
- 移动已有子任务节点只调整图结构，保留实际子任务原所属关系；普通新节点仍按当前所在分支创建。任务中已经删除的子项保留失效引用，不因折叠、拖动或重载而复活。
- 沿用任务系统最多三层子任务。过深转换在任何写入前整体拒绝，显示中英文提示；不截断、摊平或删除分支。

## 数据与失败保护

- MindMapNode 新增可选 subTaskId（必须有 taskId 作为所属任务），SubTask 新增可选 mindMapSource:{mapId,nodeId}。原任务来源保留。字段为增量扩展，旧导图与 v0.3+ 备份继续可读，导图持久版本仍为 1。
- Canvas/检查栏实时从 taskStore 解析标题与状态；库原始 HTML、样式、派生标签仍不持久化。仅显式标题修改提交 previousTitle/title，折叠和拖动不会把旧投影标题覆盖新任务；原图 revision 与实际标题都检查冲突。
- 转换先规划完整子树，再仅合并 title/subTasks 到最新任务。其他字段以及任务中后来新增的子项保留；同名节点使用不同稳定 ID，重试通过 mapId/nodeId 来源复用实际子项。
- 任务与图跨切片失败时按此次未被后续更改的字段/子项逆序补偿；其他图后来建立的引用及后续编辑受保护。来源身份支持补偿持续失败后冷启动复用已持久化子项。
- JSON 备份保留节点引用及递归子项来源；畸形来源或无 taskId 的 subTaskId 在写入前拒绝。删除原图后的来源记录仍有效，不强制要求源节点存在。
