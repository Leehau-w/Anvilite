# 导图撤回与同步目录记忆（2026-10-30）

当前支线 codex/legacy-review，基于已发布 v0.4.4。按用户新要求增加 Ctrl+Z，并修复每次启动都需重选同步文件夹。初始实现未改版本或发布。2026-11-01用户已明确授权作为v0.4.5打包发布，交付见[发布记录](release-v0.4.5.md)；不修改 D 盘 main 未提交改造。

## 思维导图

- 新增账号绑定 store action `undoMap`。每张导图保持独立、仅会话内的撤回记录，每图最多50步，总快照预算8Mi字符；不写入持久化/备份，切图不串历史，删除整图清理其历史，外部替换文档后拒绝旧撤回。
- 覆盖节点增删、分支拖拽/换边/折叠、导图/节点标题、任务关联与解除关联。历史使用可信 store 快照恢复引用；保留实际任务、子任务及转换来源，撤回转换后重试仍复用原任务。
- 显式关联任务/子任务改名通过稳定ID与标题前后值检查；只反向合并标题，不回滚状态、实际用时、优先级或后续子项。后续改名冲突则整次拒绝，不覆盖新修改。撤回产生新修订，不倒退CAS版本。
- 撤回写入失败时补偿本次标题/图写入，并保留可重试的历史；后续外部编辑仍保留。打开旧图的自动关联补齐不进入撤回历史。
- Ctrl+Z（兼容Cmd+Z）仅在导图页面处理，输入框/富文本/原生节点输入、IME组合输入、重复按键、对话框及任务弹窗不会误撤回图。开始撤回时取消未提交拖动；选择失效时回根节点。SettingsModal补充标准模态语义以阻止后台热键。

## 同步目录

- 已确认原原因：renderer仅保存路径，而主进程目录批准只在内存；导航/重启会清除批准，导致保存的路径每次都被拒绝。
- 主进程使用用户资料目录内的 `sync-directory-grants.json`，原子保存按账号选中的路径、realpath及dev/ino。只有用户通过原生文件夹选择器批准后写入；旧localStorage、导入和备份路径都不能自动授权。
- 升级后首次需重新选择一次，之后同一账号的刷新、重启、恢复数据后的reload可复用授权。账号分别保存，另一个账号不能借用未授权目录。IPC显式携带当前账号，若MCP的文档绑定已指向其他账号则拒绝。
- 保留可信顶层sender、对话框期间的文档代际、目录实体替换/真实路径改变、子目录/文件链接及路径越界检查。持久授权不取消写入时的文档代际检查；没有关闭MCP重载吊销规则。
- 缺失/损坏/符号链接的本机批准文件不授予访问；选择持久化失败不报告成功。批准记录有数量/大小限制。同步API不能读取或覆盖批准文件，即使用户选择了其上级目录；备份前置与原子快照替换规则保持。
