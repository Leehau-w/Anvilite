# 多任务卡片、分类创建与任务底色（2026-10-22）

## 用户需求与范围

在 codex/legacy-review 现有旧版修复及“待反馈”功能上增加多个任务卡片，每张可选择单个、多个或全部分类；快速创建显式选择分类；任务底色默认关联优先级，按用户回复支持单个任务手动选色。保留原架构、旧卡片位置/尺寸/隐藏集合，不合入 main 的未提交工作台改造。

## 实现与兼容

- 原任务卡 ID tasks 保留，新实例使用 tasks:UUID。复用 CardLayout，每个实例拥有自己的可选 taskFilter；无配置按全部显示。新增卡片位于已有布局最下方，隐藏保留配置，恢复复用同 ID。
- 单选最多一个分类，多选支持空集合；空多选显示为空，不隐式扩大成全部。选择使用分类稳定 key，显示名跟随区域重命名和语言；历史/已移除但仍有记录的分类仍可选择。
- 每张卡片复用同一任务记录，不复制任务。待办、进行中和今日完成均应用该卡片过滤，隐藏/删除任务排除，待反馈任务仍在原专用卡片中。
- 拖动排序在当前状态的全局顺序里置换筛选任务原占槽位，其他类别保持位置；提交前重新读取 store，避免旧卡片视图覆盖已改为待反馈的任务。
- 快速创建使用明确的分类选择控件，原生选项菜单不被矮卡片裁切；回车和完整创建共用当前选择。默认分类变化及类别删除时有明确回落，输入法组合输入的确认回车不触发创建。
- 任务底色默认四档柔和色调：紧急红、高橙、中蓝、低绿；优先级标记及文字提示保留，进行中仍通过边框和操作表达。任务列表、首页卡片、待反馈卡片和分类页使用同一个底色 helper。
- Task.backgroundColor 为可选六位 hex 或 null，缺省/null 跟随优先级。编辑抽屉支持预设及任意自选颜色，颜色属于草稿，取消不写入，恢复自动设为 null。手动色不随优先级改变而丢失，已完成任务弱化展示。颜色经主题表面混合以保持明暗主题可读性。
- 保持原 persist version 3，旧备份无 taskFilter/backgroundColor 兼容。导入验证筛选结构、颜色格式和 layout.id 唯一性，拒绝任意 CSS 或重复卡片编号；继续复用导入缺字段保留及写失败回滚规则。完整导出恢复应保留动态实例、过滤、隐藏、布局和手动色。
