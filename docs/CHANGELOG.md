# Changelog

## v0.4.2 — 2026-10-23

更新和兼容说明见 [v0.4.2 发布说明](releases/v0.4.2.md)。

- 待反馈卡片支持正文和拖柄排序，筛选后的排序保留其他分类位置，支持多卡同步与重载。
- 任务弹窗调整设置后 Enter 保存并关闭，备注 Shift+Enter 换行，保留输入法、局部编辑及未添加标签/子项草稿。

- 新增 Mind Elixir 思维导图首版：多张导图、分支展开折叠与拖拽、关联已有任务及节点转任务。
- 关联节点标题与任务双向同步，子节点按层级转为子任务并保留原有子项；子任务标题/完成状态实时回显，重复关联和失败重试去重。
- 任务状态实时同步，删除节点或导图保留实际任务；转换重试复用已创建任务，导图纳入账号隔离、备份与同步恢复。

## v0.4.1 — 2026-10-23

更新和兼容说明见 [v0.4.1 发布说明](releases/v0.4.1.md)。

- 修复待反馈任务完成后撤销错误回到待办的问题，支持重载/备份恢复后仍回到待反馈并继续拖拽。
- 待反馈支持多个独立卡片，分别显示单个、多个或全部分类；筛选、布局和隐藏状态持久保留，错分类拖入会提示且不改任务。

- 移除里程碑卡片的“手动记录”小字；支持编辑标题、日期和备注，日期显示精确到日。
- 里程碑标题/日期独立保存，保留关联任务、习惯的原始完成历史及旧奖励数据。
- 修复里程碑新建保存失败后重试可能重复创建的问题。

## v0.4.0 — 2026-10-23

升级和兼容说明见 [v0.4.0 发布说明](releases/v0.4.0.md)。

- 新增本机 stdio MCP：读取与操作任务、习惯和流程，支持独立读写权限、会话吊销、版本冲突检查及持久请求去重；设置中可复制连接配置。
- MCP 流程步骤修改按 ID 合并并保留未提供内容，习惯状态操作校验本周期，避免局部编辑覆盖或重复完成。

- 去游戏化：停用称号、成就、等级、经验和矿石；完成、撤销及删除不再结算奖励。主题直接选择。
- 首页原角色卡片改为概览，保留位置与隐藏设置；今日统计、分类与档案馆改用真实完成量和实际用时。
- 保留里程碑、能力图谱、个人数据与原星形侧栏图标；图谱以实际任务完成量或用时展示，不使用等级。真实任务/习惯历史在档案馆查看，旧个人纪念及兼容数据保留。

- 新建分类入口移至任务页顶部分类标签末尾，快速创建下拉框保留分类选择。
- 移除任务趋势额外的本月/本周数量和用时汇总，保留热力图及范围/指标切换。

- 精简任务底色区域，移除自选颜色下方的说明和预览。

- 系统模板支持新建、修改、删除和完整复制，修复右键空白；流程可拖入文件夹，系统目录来源创建副本。
- 任务分类可直接自定义，并同步到习惯和首页筛选；移除任务弹窗顶部“移入待反馈”，趋势标题精简为“任务趋势”。

- 任务底色改为随八个主题调整的莫兰迪配色：紧急红、高橙、中雾霾蓝、低暖石灰；预设不再提供绿色，旧颜色记录兼容保留。

- 习惯卡片支持多个实例及独立单选/多选/全部分类，隐藏恢复和备份保留设置。
- “成长趋势”改为“任务趋势”，支持实际完成数量和用时，以及本月/本周查看。
- 精简待反馈提示和分类前缀，多个任务/习惯卡片统一名称，直接显示所选分类名称。

- 首页任务卡片支持多个实例，每张可独立选择单个、多个或全部分类；保留旧布局并支持备份恢复。
- 快速创建加入显式分类选择，完整创建沿用所选分类，修复输入法回车误创建。
- 任务底色默认随四档优先级变化，也支持单独选色和恢复自动；首页、任务列表、待反馈和分类页统一展示。

- 首页新增“待反馈”卡片：任务可拖入等待外部结果，暂停计时并保留已有内容；任务列表、分类与编辑抽屉同步支持等待和恢复待办，旧首页布局保持。

- 任务和习惯子项支持拖动排序、就地编辑与多层添加，Dashboard 也可直接编辑子项。
- 修复勾选子项意外关闭编辑抽屉、部分恢复场景丢失子项状态的问题。
- 修复习惯跳过和撤销的经验值、今日统计、次数与子项恢复，以及跨周期刷新问题。
- 修复多段任务计时覆盖已有用时、SOP 转任务丢失三级步骤的问题。
- 加强备份内容校验与导入失败回滚，恢复 Dashboard 布局并保留隐藏卡片设置。
- 统一任务与习惯的行过渡反馈和 Dashboard 撤销提示；紧急任务增加文字标识。
- 旧版习惯记录缺少恢复快照时会说明无法撤销，避免错误扣分。

## v0.3.3 — 2026-05-13

### SOP 编辑优化

- 默认折叠步骤详情，只显示富文本摘要，减少多步骤流程编辑时的占用面积
- 支持在任意父步骤、子步骤、三级步骤下方一键插入同级步骤
- 步骤标题输入框支持按 Enter 连续新增同级步骤，并自动聚焦新步骤
- 三级步骤补齐详情编辑入口，复杂 SOP 不再只能编辑标题
- 收紧步骤卡片宽度与子步骤层级布局，让长 SOP 更适合连续编辑
- 未展开详细说明时，「添加子步骤」入口更贴近上方内容；展开详情后保留舒适间距
- 新增 SOP 富文本摘要提取测试，覆盖普通文本、关联 SOP 与截断场景

## v0.3.0 — 2026-04-14

### 新功能

**流程模块（Flows）**
- 新增第三个主 Tab（任务 → 流程 → 世界地图 → 里程碑殿堂）
- 4 种流程类型：流程型（有序编号步骤）、检查型（逐项确认）、清单型（无序列表）、日程型（时间轴）
- 流程型、检查型、清单型支持「开始执行」模式，逐步打勾、实时进度显示，退出自动重置
- 「转为任务」：将步骤一键转为任务子任务，支持自定义标题/分类/难度/优先级/截止日期
- 内置 8 个系统模板（不可编辑），可「复制为我的流程」后修改
- 文件夹管理：新建/重命名/删除文件夹，折叠状态持久化
- 仪表盘新增「我的流程」卡片，点击条目直接跳转

**子任务 / 子习惯折叠交互**
- 任务和习惯子项新增折叠按钮（勾选框右侧 `▾/▸ N/M`）
- 折叠状态跨页面持久化（uiStore，Zustand persist）
- 折叠逻辑统一覆盖：任务列表、仪表盘任务卡片、任务列表习惯 Tab、仪表盘习惯卡片
- 子项的子项同样支持独立折叠，最多 3 层嵌套

**仪表盘增强**
- 任务卡片移除 10 条上限，今日待办全量显示
- 任务卡片和习惯卡片均显示子项（compact 模式）
- 仪表盘任务切换状态时无飞出动画，改为淡出（0.15s）

**世界地图改造**
- 响应式卡片网格：`computeOptimalCols` 算法实时计算最优列数，卡片面积最大化
- 编辑模式改为单列拖拽排序（原网格多列拖拽兼容性问题已解决）
- 修复：区域内部空间返回后卡片尺寸异常（ResizeObserver 绑定丢失）
- 修复：切换 Tab 时出现缩放动画（移除 AreaCard 的 `layout` 属性）

**灵感速记**
- 仪表盘新增灵感卡片，支持拖拽排序
- `Ctrl+Shift+N` 全局唤起输入框，`Ctrl+Enter` 快速保存

### 功能增强

- **任务/习惯卡片 hover 延迟**：操作栏延迟 300ms 显示，避免鼠标扫过时频繁弹出
- **仪表盘热力图响应式**：格子大小随卡片尺寸自适应，月视图/周视图均支持
- **热力图周视图修复**：时段数据基于 GrowthEvent 真实小时统计（原均分算法已修复）
- **编辑抽屉实际用时**：实际时长输入框真正可编辑（原 React 受控 bug 已修复）
- **Electron 图标**：打包后任务栏图标正确显示

### 数据

- 导出备份新增 `sops`（流程）和 `inspirations`（灵感）字段
- v0.2 备份文件可兼容导入（流程/灵感数据为空）
- `APP_VERSION` 更新为 `0.3.0`

### 技术

- 新增测试覆盖：`systemSOPs`（17 cases）、`formatRelativeTime`（12 cases）、`computeOptimalCols`（11 cases）、`uiStore`（9 cases），共 169 tests
- 新增 `src/utils/formatRelativeTime.ts`、`src/utils/grid.ts`（纯函数提取，便于单元测试）
- 新增 `src/test/setup.ts`（Vitest 全局 localStorage polyfill）
- `vitest.config.ts` 新增 `setupFiles` 配置
