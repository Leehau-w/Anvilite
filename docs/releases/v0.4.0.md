# Anvilite v0.4.0

本版沿用原有数据目录和账号结构，集中修复数据一致性问题，增加任务、习惯、流程与本机 Agent 的使用能力。

## 更新内容

- 首页新增“待反馈”：等待回信或外部进展时暂停推进，保留任务内容和用时。
- 任务、习惯支持多个独立分类卡片，分类可自定义；任务底色跟随优先级，也可单独选色，预设随主题切换。
- 系统模板可新建、修改、删除，拖出到文件夹时创建完整副本；普通流程拖入则移动，多层步骤和富文本保留。
- 任务趋势可按实际完成数量或用时查看；保留里程碑、能力图谱、个人数据与个人纪念。
- 停用称号、成就、等级、经验和矿石奖励，8种主题直接选择；旧奖励数值保留，不自动清零或重算。
- 本机stdio MCP支持任务、习惯、流程读取与操作，默认关闭、启用后只读；按内容分别授权修改，并检查版本及重复请求。[连接说明](../mcp.md)
- 修复完成/撤销、备份恢复、计时累计、多层子项与流程详情等数据丢失及覆盖问题。
- 修复归档习惯重启后变为暂停、旧版计时默认值被迁移标记跳过的问题。

## 升级与兼容

兼容范围为 **v0.3.0 及后续 v0.3 系列版本 → v0.4.0**。本轮不提供 v0.2 及更早格式的迁移支持。

1. 升级前在旧版“设置 → 数据管理”导出JSON备份，关闭旧版后安装新版。
2. 使用原来的安装方式和账号；新版继续使用同一数据目录。已有首页位置、尺寸、隐藏设置及有效分类筛选保留。
3. 兼容范围内的旧备份仍可导入；新增的等待状态、多卡片筛选和系统模板修改会随新版备份保存。导入失败会尝试恢复原数据，不能在失败提示后当作恢复成功。
4. 本次兼容指旧版数据升级到v0.4.0。旧版程序不能完整识别新版新增内容；如需降级，请恢复升级前的备份，不要把新版存档交给旧版覆盖保存。
5. 旧奖励字段与历史个人备注保留，完成与撤销不再改变奖励值；旧版没有撤销快照的习惯不猜测恢复。

## 下载

应用754项回归和13项MCP测试通过；v0.3.0、v0.3.3合成存档通过升级与备份往返验收。安装包已做载荷比对和隔离运行，实际覆盖安装未在当前用户机器上执行。

Windows x64提供安装版与便携版，另附SHA-256校验文件。完整用法见[用户指南](../user-guide.md)。
