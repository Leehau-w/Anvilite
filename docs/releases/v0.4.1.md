# Anvilite v0.4.1

本版包含里程碑编辑和待反馈卡片的小修与功能补充。

## 更新内容

- 去掉自建里程碑卡片的“手动记录”小字，支持编辑标题、日期和备注，日期精确到日。
- 里程碑编辑保留任务、习惯原始完成时间及统计；新建保存失败后重试不会重复创建。
- 待反馈任务完成后撤销会恢复到待反馈，重载、备份恢复后仍保留来源，撤销后可继续拖拽。
- 首页支持多个待反馈卡片，每张可独立显示单个、多个或全部分类，筛选和布局会保存。可在“编辑布局 → 添加卡片”中新增。

## 升级与兼容

沿用 **v0.3.0 及以后版本**的数据兼容范围，继续使用原有账号和数据目录。升级前可在“设置 → 数据管理”导出备份，关闭旧版后安装新版；降级时使用升级前的备份。

旧版已完成任务如果没有保存完成前的状态，撤销仍回到待办，需要手动移入待反馈一次。

## 下载

提供 Windows x64 安装版和便携版。本轮按用户要求直接打包发布，沿用修改完成时已有的回归和界面验证结果，未新增测试或安装实测。
