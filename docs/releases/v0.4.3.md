# Anvilite v0.4.3

> 安装版暂缓使用：本版安装器被 Microsoft Defender 检测为 Program:Win32/Contebrew.A!ml，尚未确认是否误报。请使用经过新一轮安全检查的 [v0.4.4](v0.4.4.md)，不要关闭防护强行安装旧包。

本版改进思维导图的分支拖动和标题编辑，并统一用时显示。

## 思维导图

- 把分支拖到中心节点另一侧的空白处即可左右换边；嵌套分支可提升为该侧的根分支，整支子节点、折叠状态和任务关联都会保留。
- 右侧节点标题按 Enter 保存，Shift+Enter 换行，中文输入法选字不会误提交。
- 移除节点标题下方的保存按钮，以及任务联动说明和画布操作提示。

## 用时显示

- 底部统计精简为“今日完成 x 用时 x”，超过60分钟以“时、分”显示，例如“1时30分”“2时”。
- 分类卡片、分类详情和档案馆分类汇总采用同样的时/分格式。

## 升级与兼容

继续支持 **v0.3.0 及以后版本**的数据，沿用原有账号和数据目录。本版不更改数据结构，任务、习惯、流程、导图和首页布局继续保留。升级前可在“设置 → 数据管理”导出备份，关闭旧版后安装新版；降级时使用升级前的备份。
