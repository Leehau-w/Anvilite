# Anvilite v0.4.4

本版收紧 Windows 安装包的交付范围，更新富文本编辑器的安全依赖，并增加发布前的安全扫描。保留 v0.4.3 的思维导图、任务和用时显示功能。

## 安装包与安全修补

- 安装包只携带应用运行所需内容，移除多余依赖目录及 esbuild 等构建工具；实际打入前端的第三方依赖许可单独保留。
- 富文本相关 Tiptap 依赖统一更新到 3.32.1，ProseMirror view 更新到 1.42.8，纳入上游已公布的粘贴 HTML 安全修补。[上游公告](https://github.com/advisories/GHSA-c8x8-7fp4-3x9w)
- 发布流程增加 Windows Defender 扫描；检测到威胁、扫描失败或缺少检查结果时，阻止交付。发布附件提供扫描报告和 SHA256 校验文件。

本轮 Windows Defender 平台 4.18.26100.4、引擎 1.1.26100.4、安全情报 1.463.23.0 于 2026-10-29 完成扫描：应用目录、安装版、便携版三项均明确未检出威胁，防护设置保持开启。最终文件以附件扫描报告及 SHA256 为准。

## v0.4.3 的检测记录

v0.4.3 安装版曾被 Defender 检测为 Program:Win32/Contebrew.A!ml，发布页已添加警告、改为预发布并取消最新版标记，旧标签与附件保留。尚未获得微软对该样本的误报确认；本次清理包内容和更新依赖不能单独证明旧版检测原因。

本版仍未使用代码签名，Windows 可能显示未知发布者或信誉提醒。扫描报告只反映所记录的文件、检测引擎、安全情报和时间，不能保证所有安全软件在所有时刻给出相同结果。

## 升级与兼容

继续支持 **v0.3.0 及以后版本**的数据，沿用原账号和数据目录；本版不改变备份及业务数据格式。任务、习惯、流程、思维导图和首页布局继续保留。升级前可在“设置 → 数据管理”导出备份，关闭旧版后安装新版；降级时使用升级前的备份。
