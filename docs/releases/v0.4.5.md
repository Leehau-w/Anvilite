# Anvilite v0.4.5

本版增加思维导图撤回快捷键，修复同步文件夹在刷新或重启后反复要求选择的问题。

## 更新

- 思维导图支持 **Ctrl+Z** 撤回节点增删、分支拖动/折叠、标题及任务关联操作；每张图独立保留本次会话的最近50步。
- 撤回不会删除已创建的实际任务或子任务，也不会回退任务的完成状态、用时或后续修改。标题发生冲突时提示并保留新修改；输入框和弹窗保留原有键盘行为。
- 同步文件夹在本机按账号记住，刷新、退出重启及切回账号后无需重复选择；目录被替换或不可用时仍会要求重新选择。

## 升级

继续支持 **v0.3.0 及以后版本**，保留账号、任务、习惯、流程、导图和首页布局。同步授权改为本机保存，升级后首次需重新选择一次同步文件夹，之后会记住。授权不会通过导出备份自动传到其他设备。

## 安装包安全检查

沿用v0.4.4收紧后的打包范围，仅交付应用运行所需内容及第三方许可。发布前要求Defender扫描应用目录、安装版、便携版，并对GitHub下载件再次扫描；结果以附件扫描报告和校验文件为准。

2026-11-01，本地应用目录、安装版和便携版三项均通过 Defender 扫描，未检出威胁；安全情报 1.463.76.0、引擎 1.1.26100.4，实时防护保持开启。

本版未使用代码签名，Windows仍可能显示未知发布者或信誉提醒。安全扫描结果仅适用于记录的文件、情报版本和时间，不能保证所有安全软件始终给出相同结果。
