# Anvilite · 锻石 — 用户指南

> 当前版本：v0.4.0。支持 v0.3.0 及后续 v0.3 系列数据升级读取；降级到旧版时请恢复升级前备份。

---

## 一、产品定位

Anvilite 是一款个人任务与习惯管理桌面应用，支持分类、流程、灵感记录和自由布局的首页。任务和习惯的进展通过真实完成记录与用时呈现。

---

## 二、日常使用

快速记录任务与想法，按分类安排工作；执行时计时，等待外部结果时移入待反馈，完成后查看任务趋势、里程碑和个人数据。常用步骤可以保存为流程，重复执行或转为任务。

## 三、功能模块

### 3.1 仪表盘（Dashboard）

应用主页，可拖拽、调整大小、显示/隐藏的卡片布局。

| 卡片 | 功能 |
|------|------|
| 任务列表 | 支持多张独立卡片，展示待办、进行中及今日完成；每卡可显示单个、多个或全部分类，支持子项与拖拽排序 |
| 习惯追踪 | 支持多张独立卡片及单个、多个或全部分类；展示今日到期与本周期完成的习惯，含子项、完成及撤销 |
| 概览 | 用户名、当前活动状态、待办任务及活跃习惯数量 |
| 统计面板 | 今日完成任务与习惯的合计数量、今日完成任务的实际用时 |
| 快速创建 | 显示当前分类，可切换后回车创建，或带着所选分类打开完整创建 |
| 任务趋势 | 按实际完成任务的数量或实际用时查看，支持本月 / 本周四时段，格子大小随卡片尺寸自适应 |
| 灵感记录 | 未转化的灵感列表，支持拖拽排序、点击编辑、快速转为任务 |
| 我的流程 | 流程模块的快捷入口，展示文件夹与流程列表，点击直接跳转；文件夹可折叠 |
| 待反馈 | 支持多张独立卡片，可按单个、多个或全部分类查看等待外部进展的任务；支持拖入、恢复待办、完成及撤销 |

**多个任务、习惯与待反馈卡片**

- 点击“编辑布局 → 添加卡片”，选择“新增任务卡片”“新增习惯卡片”或“新增待反馈卡片”，均可重复添加。新卡片放在原布局下方，可自行调整大小、位置或隐藏。所有任务卡片统一名为“任务”，习惯卡片统一名为“习惯”，待反馈卡片统一名为“待反馈”。
- 点击每张卡片右上角的分类名称（默认“全部”），独立选择全部、单个或多个分类。多选时直接显示所选名称；全部取消后显示“未选择”，卡片内容为空。
- 同一任务或习惯可出现在多张卡片中，完成、编辑等操作同步更新，记录不会因卡片变多而复制。筛选不会更改原记录的分类，隐藏后恢复卡片保留筛选与位置。单分类习惯卡片的添加按钮会沿用该分类。
- 卡片布局、隐藏设置和分类筛选会随正常保存、备份及同步恢复保留。

**任务趋势**

- 可切换“完成数量”或“完成用时”，以及本月 / 本周。周视图按凌晨、上午、下午、晚上分成四个时段。
- 统计当前已完成、未删除的主任务，按实际完成日期记录；隐藏任务仍计入，撤销完成会移除，更改实际用时会同步更新。
- 用时为任务记录中的实际分钟数，未填写按 0 计；不以预估时间或等待时间代替。格子提示同时显示任务数量和实际分钟数。

**灵感速记快捷键**：`Ctrl+Shift+N` 随时唤起灵感输入框，`Ctrl+Enter` 快速保存。

### 3.2 任务系统（Tasks）

**创建**

- 顶部输入框快速创建（回车确认），旁边显式选择分类；完整创建会沿用该选择。输入法选字回车不会误创建任务。
- 右侧抽屉完整编辑：标题、分类、优先级（紧急 / 高 / 中 / 低）、截止日期、实际用时、底色和备注
- 最后填写的实际用时在任务完成后可在抽屉中补录

**任务底色**

- 默认底色采用莫兰迪色系：紧急为灰玫瑰红、高为暖杏橙、中为雾霾蓝、低为暖石灰，不提供绿色预设；已完成任务弱化显示。
- 在编辑抽屉中更改优先级，首页卡片、任务列表、待反馈卡片和分类页的底色会同步变化。
- 编辑抽屉的“任务底色”可为单个任务选择预设颜色或自选颜色，也可点击“跟随优先级”恢复自动配色；取消编辑不会保存草稿颜色。
- 预设另有燕麦米、灰藕紫和可可棕，随主题调整色调与明暗强度；自选颜色保留并与主题底面融合。更改优先级会保留手动选择，优先级标记和文字提示仍可配合识别。

**自定义分类**

- 在任务页顶部分类标签末尾点击“＋”，或任务弹窗里点击“自定义分类”，输入名称后创建并选中。首页和任务页快速创建的分类下拉框只负责选择已有分类。
- 新分类共用于任务、习惯及首页卡片筛选，也会随备份保存；重复名称会选中已有分类。分类页可以继续重命名或删除。
- 沿用现有12个分类的数量上限；取消新建不会写入分类，也不会提交任务草稿。

**子任务**

- 在编辑抽屉中添加子项，最多 3 层嵌套（根 → 子 → 孙）
- 子任务作为父任务内部清单管理，不单独计入主任务完成量
- 删除父任务会级联删除所有子孙任务
- 有子任务的任务，勾选框右侧显示折叠按钮（`▾/▸ N/M`），点击收起/展开子任务列表，折叠状态跨页面持久保存；子项的子项同样可折叠

**完成与撤销**

- 勾选框完成任务，递归完成内部子项；完成记录保留任务名称、分类与实际用时
- 完成后 5 秒内可通过 Toast 撤销；已完成列表也可随时撤销
- 撤销移除本次完成记录，保留任务内容和已记录用时；从待反馈完成的任务恢复为待反馈，其他任务恢复为待办，计时不自动启动。旧完成记录未保存来源状态时仍恢复待办

**排序与筛选**

- 状态自动分组：进行中 → 待办 → 待反馈 → 已完成
- 拖拽可手动调整同分组内的任务顺序
- 顶部分类 Tab 筛选任务

**待反馈**

- 对暂时无法主动推进的任务，在正常浏览首页时，抓住任务左侧的小拖柄，拖进“待反馈”卡片。
- 也可通过任务右键菜单设置；任务列表和分类页同步显示等待状态。
- 待反馈卡片可重复添加并独立筛选分类。拖入任务必须符合目标卡片当前筛选，不匹配时会提示；不会为了移入卡片而修改任务分类。
- 进入等待会暂停正在运行的计时，保留此前累计用时、子项、标签、分类、备注和截止日期。
- 收到回复后点击“恢复待办”，任务回到待办组，计时仍保持暂停；已经解决的任务可直接勾选完成。
- 等待状态会随正常保存、备份导入和同步恢复保留。首页编辑布局模式仍用于移动、调整或隐藏卡片。
- 升级已有首页时，新卡片补到原布局下方；原卡片位置和隐藏设置保留。若所有卡片已被隐藏，可通过卡片管理自行添加。

**已完成任务分组视图**

- 支持按月份、按区域分类、自定义分组三种方式归档完成的任务
- 自定义分组支持拖拽将任务移入/移出分组

### 3.3 习惯系统（Habits）

**创建**：名称、分类、重复周期（每天 / 工作日 / 每周 / 隔周 / 每月 / 自定义），在区域内部空间或任务列表的习惯 Tab 中管理。习惯子项可折叠展开（折叠按钮位于完成按钮右侧），折叠状态持久保存。

**重复模式**

| 模式 | 说明 |
|------|------|
| 每天 | 每日出现 |
| 工作日 | 周一至周五 |
| 每周（严格）| 指定周几出现 |
| 每周（弹性）| 每周完成 N 次，自由安排 |
| 隔周 | 每 14 天一次 |
| 每月 | 每月一次 |
| 自定义 | 每 N 天一次 |

**连续机制**

- 完成 → 连续次数 +1
- 跳过 → 连续次数 -10%（下取整）
- 缺席 → 连续次数 -50%，若有容错充能则抵消
- 容错充能：首次连续 7 次获得 1 次，之后每 14 次获得 1 次（上限持有 1 次）

**当日撤销**：完成习惯后，当天内可通过仪表盘习惯卡片右侧的撤销按钮取消本次完成。

**状态流转**
```
active → completed_today（次日 0 点自动恢复 active）
active ⇄ paused（暂停 / 恢复）
active → archived（完成并归档）
active → hidden（隐藏）
```

### 3.4 流程模块（Flows）

将常用的操作步骤、清单或日程固化为可复用的「流程」，随时查阅或一键转化为任务。

**侧边栏入口**：流程；星形图标进入里程碑，可查看能力图谱、个人数据和个人纪念。

**流程类型**

| 类型 | 用途 |
|------|------|
| 流程型 | 有顺序的操作步骤，带编号圆圈 |
| 检查型 | 需要逐项确认的清单 |
| 清单型 | 无顺序的物品或待办列表 |
| 日程型 | 按时间排列的计划（含时间标注）|

**执行模式**

流程型、检查型、清单型支持「开始执行」模式：
- 步骤前出现勾选框，点击勾选即划线淡化
- 顶部实时显示完成进度（n/N 已完成）
- 点击「结束执行」退出，勾选状态不保存（下次执行重新开始）

**转为任务**

点击底部「转为任务」，可将流程步骤直接生成为任务的子任务：
- 可自定义任务标题、分类、优先级、截止日期
- 可勾选要包含的步骤（默认全选）
- 步骤中的子步骤映射为嵌套子任务（最多 2 层）

**系统模板**

内置 8 个系统流程，按类型分组：
- 检查型：每周复盘、会议准备检查
- 流程型：项目启动流程、学习新技能流程
- 日程型：工作日日程、休息日日程
- 清单型：出差准备清单、大扫除清单

系统模板文件夹支持右键新建流程、子文件夹、重命名和删除；其中的流程可以直接编辑、删除，也可复制为自己的流程。拖动流程到文件夹：系统模板目录中的流程会创建独立副本，原模板保留；普通流程会移动到目标目录。复制保留完整子步骤及详细说明。删除系统模板文件夹及内容后，重启或恢复该备份不会自动重新出现。

**文件夹管理**

- 可新建、重命名、删除文件夹；删除会包含其中的流程与子文件夹
- 文件夹折叠状态持久化保存

### 3.5 分类

分类页支持创建、重命名、排序和删除分类，最多 12 个。每个分类展示当前有效已完成主任务的数量及实际用时；隐藏的已完成任务计入，已删除任务不计入。

进入分类后，可管理该分类中的任务与习惯，查看任务记录，并选择已经拥有的装饰与背景。已有装饰保留。

### 3.6 档案馆

档案馆提供任务、习惯的实际完成量与时间统计，以及真实活动记录。记录包含任务完成、习惯完成、跳过、未完成与手动纪念。旧版纯奖励事件不再展示，保留在备份中。

### 3.7 里程碑

侧边栏星形图标进入“里程碑”，保留已有个人纪念，支持新增、编辑标题/日期/备注和确认删除，日期精确到日。修改里程碑日期不改变任务或习惯的实际完成时间。普通任务、习惯的日常历史在档案馆查看。旧奖励记录上保存的个人备注仍保留，以中性的纪念标题显示。

能力图谱按分类展示有效已完成主任务的数量或实际分钟数，可切换指标；自定义分类和已有记录使用过的分类同样计入。隐藏任务计入，已删除任务和无效完成日期不计入；子任务不重复累计。

个人数据展示任务完成量、已完成任务用时、习惯累计完成次数、各习惯中最大的当前连续完成次数、使用天数及未完成任务量。归档习惯保留累计次数，已删除习惯不计入；使用天数按本地日历计算，创建当天计为一天。这些数据不会触发经验、矿石或等级奖励。

### 3.8 设置

- **账号管理**：创建、切换、删除本地账号，各账号数据隔离。
- **用户名**：自定义显示名称。
- **主题**：8 种主题直接选择，无需购买或解锁；4 套亮色、4 套暗色。
- **语言**：中文 / English，运行时切换。
- **存储空间**：显示本地存储用量，接近上限时提示。
- 称号、成就、等级、经验与矿石系统已停用，完成、撤销、删除任务或习惯均不结算奖励。

## 四、数据与存档

- 数据存储在本地，支持离线使用；可选择云盘同步目录进行手动快照备份与覆盖恢复
- 每个账号独立存储，key 前缀隔离
- 支持**数据导出**（JSON 格式备份）和**数据导入**（从备份恢复）
  - 备份内容包含：任务、习惯、流程、灵感、分类、首页布局及筛选、设置、活动记录；旧奖励字段为兼容原样保留，不再更新或重算
  - v0.2 备份文件可导入 v0.3（流程和灵感数据将为空）
- 入口：设置 → 数据管理

---

## 五、连接 Agent

设置中的“Agent 连接 · MCP”提供本机 stdio 连接，支持任务、习惯与流程的受控读写。默认关闭，首次开启只读；权限按内容分别设置。连接、重试与版本冲突规则见 [MCP 使用说明](mcp.md)。

## 六、键盘快捷键

| 操作 | 快捷键 |
|------|--------|
| 唤起灵感速记 | `Ctrl+Shift+N` |
| 灵感速记快速保存 | `Ctrl+Enter`（输入框内）|
| 退出区域内部 | `ESC` |
| 确认输入 | `Enter` |
| 取消输入 | `ESC` |
